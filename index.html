1. 資料概覽

本資料集整理高速公路瓶頸路段之 ETC OD 旅次、5 分鐘交通狀態、 氣象資訊與日曆／假期資訊。

研究期間 2024-01-01 至 2025-12-31
Master 資料單位 一列 = 一筆通過研究瓶頸的 M06B 旅次
M05A 時間尺度 5 分鐘
Weather 時間尺度 1 小時

研究方向

路段 方向
國道3號 大溪 → 龍潭
國道3號 龍潭 → 大溪
國道5號 坪林 → 頭城
國道5號 頭城 → 坪林

2. V1 Core Master 資料架構

M06B + M05A + Weather + Calendar / Holiday
↓
V1 Core Master

Master Data 保留原始旅次層級資訊， 因此不會失去 VehicleID、OD、 TripInformation 等資訊。

重要： Master Data 並不是最終的 5-minute modeling dataset。 後續壅塞預警模型會另外從 Master 聚合成「一列 = 一個 5 分鐘時段」， Master 本身永久保留。

4. Data Dictionary

A. 資料識別與時間
欄位 單位 / 型態 定義
MasterRoute string 研究瓶頸路段， 如 N3_Daxi_Longtan。
MasterDirection N / S 行車方向。
BottleneckTime datetime 該筆旅次實際通過研究瓶頸的時間。
Time5 datetime 與 M05A 對應的 5 分鐘時階。
WeatherTime datetime 對應氣象資料的小時時間。
CalendarDate date BottleneckTime 所屬日期。
Hour 0–23 通過瓶頸的小時。
Minute 0–59 通過瓶頸的分鐘。
B. M06B — ETC 旅次 / OD
欄位 單位 / 型態 定義
VehicleID string 匿名化車輛識別碼。 同一 ID 可跨日重複出現。
VehicleType category 31 小客車、 32 小貨車、 41 大客車、 42 大貨車、 5 聯結車。
DetectionTimeO datetime 旅次起點門架偵測時間。
GantryO string 旅次起點 ETC 門架。
DetectionTimeD datetime 旅次終點門架偵測時間。
GantryD string 旅次終點 ETC 門架。
TripLength km 此筆旅次行駛距離。
TripEnd Y / N 是否為旅次結束紀錄。
TripInformation string 此旅次依序通過的門架與時間資訊。
BottleneckGantry string 判定該旅次通過研究瓶頸所使用的門架。
C. M05A — 5 分鐘交通狀態

各車種速度

欄位 單位 定義
M05_Speed_31 km/h 小客車站間速度。
M05_Speed_32 km/h 小貨車站間速度。
M05_Speed_41 km/h 大客車站間速度。
M05_Speed_42 km/h 大貨車站間速度。
M05_Speed_5 km/h 聯結車站間速度。

各車種交通量

欄位 單位 定義
M05_Volume_31 veh / 5min 小客車交通量。
M05_Volume_32 veh / 5min 小貨車交通量。
M05_Volume_41 veh / 5min 大客車交通量。
M05_Volume_42 veh / 5min 大貨車交通量。
M05_Volume_5 veh / 5min 聯結車交通量。
M05_Volume_Total veh / 5min 五車種有效交通量合計。

加權速度

Vt = Σ( Speedk,t × Volumek,t ) / Σ Volumek,t

M05_Speed_Weighted 為各車種速度依交通量加權後的 綜合站間速度。

此欄位為本研究自行建立之 composite indicator， 不是高速公路局直接提供的 「全車平均速度」。
欄位 定義
M05_Speed_OwnType 此筆 M06B 車輛所屬車種， 在相同 5 分鐘的 M05A 速度。
M05_Volume_OwnType 此筆車輛所屬車種， 在相同 5 分鐘的交通量。
M05_Matched 是否成功匹配 M05A。
D. Weather
欄位 單位 定義
Weather_Temperature_C °C 小時氣溫。
Weather_Dewpoint_C °C 小時露點溫度。
Weather_Precipitation_mm mm 小時降雨量。
Weather_WindSpeed_mps m/s 小時風速。
Weather_Matched boolean 是否成功匹配氣象資料。
E. Calendar / Holiday
欄位 定義
WeekdayNum 星期一=1 ～ 星期日=7。
IsWeekend 是否為週六或週日。
IsLongHoliday 是否位於連假正式期間。
HolidayName 正式連假名稱。
IsPreLongHoliday 是否為連假前一天。
PreLongHolidayName 即將到來之連假名稱。
IsStandaloneHoliday 是否為單日假日。
StandaloneHolidayName 單日假日名稱。
DayType WEEKDAY / WEEKEND / PRE_LONG_HOLIDAY / LONG_HOLIDAY / STANDALONE_HOLIDAY
HolidayEventName D-3 至 D+2 事件窗所屬假期名稱。
HolidayDaysTotal 該假期總天數。
HolidayDayIndex 若為正式假期， 表示該日為假期第幾天。
HolidayPhase NORMAL、 D-3、D-2、D-1、 Holiday_D1 ... Holiday_Last、 D+1、D+2。
HolidayPhaseGroup NORMAL / PRE / HOLIDAY / POST。
IsHolidayWindow 是否位於 D-3 至假期結束後 D+2。
IsSummer 7/1 至 8/31 = 1。 為本研究之暑假操作性定義。
Calendar_Matched 是否成功匹配日曆資料。

5. 如何讀取資料

Python

file = r"D:\統計實務\Data\MASTER_V1_2024_2025\N3_Daxi_Longtan_N_2024_2025_MASTER_V1.parquet"

print(df.shape)
print(df.columns.tolist())
print(df.head())

Python：只讀需要的欄位 

cols = [
    "VehicleID",
    "VehicleType",
    "BottleneckTime",
    "GantryO",
    "GantryD",
    "TripLength",
    "M05_Speed_Weighted",
    "M05_Volume_Total",
    "Weather_Precipitation_mm",
    "DayType",
    "HolidayPhase"
]

df = pd.read_parquet(
    file,
    columns=cols
)
