觀測單位

V2_LITE 仍維持與 M06B 相同的觀測單位：

一列 = 一筆 M06B 旅次

VD 的五分鐘交通狀態會依照旅次的 BottleneckTime 對應至五分鐘時間， 再將相同時間的 VD 資訊加入旅次資料。

五分鐘合併鍵只用於資料建置過程， 最終 V2_LITE 不額外保留 Time5 欄位。

刻意不加入的欄位

為保持 V2_LITE 精簡， 以下資訊不直接加入旅次資料：

不加入的資訊 原因
VDType 保留於獨立 VD 資料進行追蹤， 避免在大量旅次中重複文字欄位
Lane-level Speed / Occupancy 後續主要分析使用測站層級代表值
Primary VD 可依不同分析目的動態決定
有效 VD 數量 屬於可即時計算的衍生變數
壅塞旗標 可依不同速度門檻重新定義
Min / Mean / Median Speed 屬於 EDA 或建模階段的衍生特徵

VD 特殊值注意事項

V2_LITE 中的 VD Speed 保留原 VD_LITE 的特殊狀態碼。

Speed 意義
-1 沒有偵測到車輛
-99 官方速度資料無效
-999 XML 有，但該 VD 不存在
-9999 該分鐘官方 XML 無法取得
進行速度平均、 壅塞門檻判定或模型分析前， 必須先將這些狀態碼 與正常速度值分開處理。
