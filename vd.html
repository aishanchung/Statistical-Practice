VD — 車流偵測器資料

整理瓶頸附近 VD 測站之車速、 佔有率與設備狀態， 用來描述局部道路交通狀況。

資料來源與抓取方式

VD 歷史資料來自高速公路局歷史資料庫。 本研究以每五分鐘為一個目標時間， 從歷史 VD XML 中擷取瓶頸附近主線測站資料。

原始抓取程式會依序嘗試： 目標時間 → 目標時間 + 1 分鐘 → 目標時間 - 1 分鐘。 只要找到可下載的 XML 檔案， 即使用該檔案內容進行後續整理。

速度整理方式

同一個 VD 測站可能同時包含多個車道。 整理後保留各車道速度與佔有率， 並使用佔有率作為權重計算測站代表速度。

各車道速度 × 各車道佔有率
↓
加總後除以總佔有率
↓
測站代表速度
若所有可用車道皆沒有正的佔有率， 則不直接將速度視為 0 km/h， 避免把「沒有偵測到車」 誤判為「車速為 0 的嚴重壅塞」。

缺失資料檢查

目前正在針對國道 3 號 VD 於 2024–2025 期間的缺失時段， 重新回查高速公路局歷史 XML。

整理後資料中的缺失不一定表示 高速公路局原始資料本身缺失。 可能原因包括原始 XML 缺檔、 個別 VD 未出現在該 XML、 速度為異常值， 或當初下載過程未成功取得資料。 因此缺失原因確認完成前， 暫不直接進行補值。
