速度與佔有率整理方式

各 VD 可能包含多個車道。 正式資料不保留每一個車道的欄位， 而是將車道資訊整理成測站層級的代表值。

代表速度採用 Occupancy 作為權重：

Speed = Σ（車道速度 × 車道 Occupancy） ÷ Σ（車道 Occupancy）

若部分車道資料無效， 但仍有其他有效車道， 則只使用有效車道進行計算。

當所有有效車道的 Occupancy 都為 0 時， 代表該時間沒有偵測到車輛。 此時 Speed 設為 -1， 而不是 0 km/h， 避免被誤判為嚴重壅塞。

特殊值定義

Speed 值 意義
≥ 0 正常有效速度
-1 VD 有資料， 但所有有效車道 Occupancy 為 0
-99 官方資料存在， 但沒有有效速度
-999 官方 XML 存在， 但該 VD 未出現在 XML
-9999 該時間的官方歷史 XML 不存在或無法取得
-1、-99、-999、-9999 都是資料狀態碼， 不可直接當作真實速度值 計算平均或投入模型。

缺失資料重新檢查

原整理資料中存在部分缺失時段。 為確認缺失原因， 重新回查官方歷史 XML， 只針對原本缺少的 TargetTime × VDID 進行檢查。

結果顯示缺失並非全部屬於相同原因， 主要包含：

情況 處理
官方 XML 存在， 但 VD 未出現 保留為 VD_ABSENT
VD 存在， 但速度無效 保留為 OFFICIAL_NA
官方歷史 XML 不存在 保留為 FILE_UNAVAILABLE
重新查詢可取得有效資料 放回正式 VD， 並以 RECOVERED 類型記錄
共重新取得 266 筆 有效資料： 5 筆原時間、 95 筆前 1 分鐘、 166 筆後 1 分鐘。
RECOVERED_P1 使用的是目標時間後 1 分鐘資料。 進行歷史 EDA 時可使用， 但若未來進行即時預測， 必須避免將未來資訊作為預測當下的解釋變數。
