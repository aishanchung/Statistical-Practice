正式 VD_LITE 結構

正式 VD 檔採長格式，一列代表一個時間點的一支 VD，只保留必要欄位。

#欄位說明
1TargetTime五分鐘分析時間鍵，使用台灣本地時間
2VDIDVD 測站代碼
3Speed以佔有率加權後的測站代表速度

不保留 Lane0～Lane4、主要 VD、有效 VD 數量、壅塞旗標等大量衍生欄位。 需要時再由這份基礎資料計算，避免資料表過度膨脹。

速度與佔有率整理方式

同一支 VD 可能同時有多個車道資料。 速度使用佔有率作為權重，只使用速度與佔有率皆可用、且佔有率大於 0 的車道。

Speed

Occupancy 則取可用車道佔有率的算術平均。 若所有可用車道佔有率皆為 0，代表該時間沒有偵測到車，Speed 設為 -1，而不是 0 km/h。

特殊值定義

數值使用欄位意義
>= 0Speed / Occupancy正常可使用的交通資料
-1SpeedVD 有觀測，但所有可用車道 Occupancy = 0，視為沒有偵測到車
-99Speed 或 OccupancyVD 存在，但官方該變數為無效值或缺測
-999Speed / Occupancy官方 XML 存在，但該 VDID 沒有出現在 XML
-9999Speed / Occupancy官方歷史 XML 本身不存在或無法取得
所有負數都是資料狀態碼，不是真實速度或佔有率。 計算平均速度、建模或繪圖時，必須先排除負數狀態碼。

缺失資料回查結果

原整理檔缺失資料已重新回查高速公路局歷史 XML。 缺失主要不是單純的下載漏抓，而是可以區分成「VD 不在 XML」、「官方速度無效」與「歷史 XML 缺檔」等不同情況。
