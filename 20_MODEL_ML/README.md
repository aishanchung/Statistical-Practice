# 20_MODEL_ML — 本機程式與 V3 EDA 結果封存

本目錄依 2026-11-05 上傳的 `20_MODEL_ML.zip`，保留可讀的研究程式與說明檔，整理成固定版本。以原有的繁體中文分類目錄保存，避免與 `10_OD-analysis/` 中已經測試、持續維護的最新版程式互相覆寫。

- `01_資料抓取/`：OD/VD 來源下載與缺失原因查核。
- `02_資料分割/`：瓶頸路段切割。
- `03_資料彙總/`：V1/V2/V3 與 VD、Y 建構。
- `04_資料清洗/`：資料稽核與清理。
- `05_EDA/`：初步 EDA、OD 門檻探索及所需套件。
- `06_clustering/`：分群方法的初期研究程式及文字說明；動畫未納入本次程式封存。
- `07_VD/`：VD 缺值處理、長缺漏驗證工具與 Windows 操作說明。
- `10_OD analysis/`：V3 整段 EDA、天氣檢核、OD 初步分析，以及可公開的較小彙整 CSV。

本次共封存 **45 份程式／說明檔**與 **20 份小型 V3 EDA CSV**。刻意不公開體積較大的 Parquet 原始資料、含每筆交通紀錄的明細、驗證中間產物、快取、動畫與影片。必要研究圖表已另放在網站的 `assets/v3/`。

**使用前請注意**：本目錄是使用者原始程式的可追溯快照，未經重新執行或整合測試；Windows 路徑及相依套件須依本機環境調整。正式研究規範與已驗證的 2024 OD 分群 Pilot，仍請以 [10_OD-analysis](../10_OD-analysis/README.md) 為準。

網站主頁為 [index.html](../index.html)，V3 介紹在 [v3_lite.html](../v3_lite.html)。
