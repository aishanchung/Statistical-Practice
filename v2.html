V2 的 observation unit 仍然是 一列 = 一筆 M06B trip。 同一 Time5 的多筆 trip 會共享相同的 VD traffic context。

VD Time Definition

VD 並不是 5-minute average。 本研究使用五分鐘 Target Time， 並以鄰近的一分鐘 VD observation 作為該時間格點的 traffic snapshot。

有效 Snapshot： |Target Time - DataCollectTime| ≤ 4 minutes

VD Data Quality Rules

問題 處理方式
|Lag| > 4 min ValidSnapshot = FALSE
沒有 usable speed Speed = NA
All lane Speed = 0 且 Occupancy = 0 NoTrafficLike flag， 不直接判定為壅塞
Missing VD Congestion = NA， 不直接視為 non-congestion
Speed > 180 km/h REVIEW flag， 不自動刪除

Dynamic Primary VD

每個 Time5 從當下有效 VD 中， 選擇距離研究瓶頸 eTag 最近的一支 sensor。

因此 Primary VD 不是永久固定同一支。 若最近的 VD 當下 invalid， 可改用下一支距離較近的有效 VD。
